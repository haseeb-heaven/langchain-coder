## 2026-07-12 - Remove Insecure eval() Usage in State Checking
**Vulnerability:** The application used Python's `eval()` function to dynamically evaluate strings representing Streamlit session state variables in `script.py` (e.g., `eval('st.session_state.project')`). This is a severe anti-pattern that can lead to arbitrary code execution if the evaluated string incorporates any unsanitized user input or is manipulated.
**Learning:** Using `eval()` to check dictionary keys or object attributes is unnecessary and dangerous. The developer intended to dynamically check state variables mapped in a dictionary, but mistakenly used strings of code instead of accessing the state object directly.
**Prevention:** Never use `eval()` to dynamically evaluate code strings or check dictionary values. Instead, use safe state access methods like `st.session_state.get(key)`. Use simple strings for dictionary keys, representing the state variable names, and look them up dynamically in the session state dictionary.
