## 2026-08-12 - Added Tooltips to Action Buttons
**Learning:** In Streamlit apps with dense toolbars, users can benefit from additional context for action buttons. Adding the `help` parameter to `st.form_submit_button` provides native tooltips without cluttering the UI, improving usability and accessibility for screen readers.
**Action:** Always include descriptive `help` parameters for form submit buttons to clarify their function.
