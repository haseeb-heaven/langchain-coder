## 2026-07-28 - Added helpful tooltips to form action buttons
**Learning:** Adding the `help` parameter to Streamlit `st.form_submit_button` provides accessible tooltips to icon-only or generic-action buttons without cluttering the UI, acting as a quick micro-UX win for better discoverability.
**Action:** Use Streamlit's native `help` parameter on interactive elements to explain actions, especially when space is constrained or functionality isn't immediately obvious.
