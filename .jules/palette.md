## 2024-05-18 - Tooltips on form submit buttons
**Learning:** Adding the `help` argument to `st.form_submit_button()` provides native tooltips that explain button actions without cluttering the UI, which is an effective micro-UX pattern for complex interfaces.
**Action:** Consistently use the `help` parameter on all interactive components like buttons in Streamlit apps to improve clarity, especially when icon-only or generic labels are used.
