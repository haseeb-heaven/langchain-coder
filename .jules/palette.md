## 2026-08-04 - Added Tooltips to Streamlit Buttons
**Learning:** Streamlit's `st.form_submit_button` has a native `help` parameter that creates helpful tooltips when hovered over. This is a very simple and standard pattern to improve UX without requiring custom CSS or extra components.
**Action:** Always use the `help` parameter for primary buttons and form buttons to provide additional context to users in Streamlit applications.
