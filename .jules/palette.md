## 2024-05-24 - Add help tooltips to form submit buttons
**Learning:** Adding `help` text to `st.form_submit_button` provides immediate contextual understanding for users without cluttering the UI, acting as a lightweight tooltip to improve accessibility.
**Action:** Use the `help` parameter in `st.form_submit_button` and other Streamlit input widgets to clarify the button's action for users, especially for those relying on screen readers or needing more context.
