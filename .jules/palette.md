## 2026-10-02 - Enhance Streamlit Form Submit Buttons with Tooltips
**Learning:** Adding the `help` parameter to standard Streamlit inputs like `st.form_submit_button()` provides essential context for form actions. This is a crucial UX pattern for minimizing user confusion in data apps.
**Action:** Always include a descriptive `help` string on functional buttons to ensure screen readers and visually impaired users understand the button's action.
