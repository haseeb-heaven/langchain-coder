## 2026-08-15 - Adding Tooltips to Streamlit Submit Buttons
**Learning:** In Streamlit applications, a quick micro-UX enhancement is to add the `help` parameter to `st.form_submit_button()` calls. It provides valuable contextual guidance to users hovering over the buttons without cluttering the UI.
**Action:** Always check existing Streamlit form submit buttons for missing `help` tooltips and add descriptive ones when improving application accessibility and usability.
