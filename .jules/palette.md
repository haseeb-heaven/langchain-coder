## 2026-08-03 - Adding Tooltips to Streamlit Submit Buttons
**Learning:** Adding informative tooltips via the `help` parameter to Streamlit's `st.form_submit_button` calls provides better context and accessibility, especially when buttons are closely grouped or perform complex backend actions.
**Action:** Always include a descriptive `help` string when creating primary action buttons in Streamlit to improve user guidance without cluttering the UI.
