## 2026-09-27 - Adding Tooltips to Dense Action Bars
**Learning:** Using Streamlit's `help` parameter on buttons (`st.form_submit_button`) provides a simple, native way to add tooltips. This is a highly reusable UX pattern for clarifying the purpose of action buttons in dense UIs without taking up additional layout space.
**Action:** Consistently apply the `help` parameter to all interactive components (buttons, inputs) in Streamlit apps to provide inline context and improve accessibility/usability for screen readers and sighted users.
