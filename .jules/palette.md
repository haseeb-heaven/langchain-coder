## 2026-08-14 - Adding Tooltips to Interactive Elements
**Learning:** Adding the `help` parameter to Streamlit components like `st.form_submit_button` provides accessible tooltips that clarify actions without cluttering the UI, acting as a quick micro-UX win for icon-only or generic buttons.
**Action:** Consistently leverage the `help` parameter on interactive Streamlit widgets where the action might not be entirely obvious or when a little extra context helps user confidence.
