## 2026-10-20 - Add Tooltips to Main Configuration Settings
**Learning:** Utilizing Streamlit's built-in `help` parameter across main input elements (like `st.selectbox`, `st.radio`, and `st.checkbox`) provides an immediate, frictionless micro-UX improvement by rendering native tooltips. This is particularly effective for settings panels where users might need extra context without cluttering the UI with permanent helper text.
**Action:** Consistently use the `help` parameter on key configuration inputs and form elements in Streamlit applications to enhance accessibility and user understanding, especially for technical settings like API modes or provider selections.
